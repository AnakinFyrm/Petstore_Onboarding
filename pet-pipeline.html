一句「有猫吗？」是怎么走完全程的

从你在 CLI 里敲下一行字，到这句话变成一次真正打到 PostgreSQL 的 SQL 查询、再把结果说回给你 —— 这张图画的是这条路径实际经过的每一跳，以及哪一跳是真正的进程边界。

同进程函数调用 跨进程 / 网络调用 MCP 白名单过滤边界
这条流水线上唯一被强制的安全边界

pet-mcp 这个 MCP 服务器本身可以暴露任意多个工具，但 pet-aes 的 build_agent() 会把传进来的 toolset 过滤到 PETSTORE_AGENT_SPEC 声明的那三个名字——pet_mcp_search_pets、 pet_mcp_get_pet、pet_mcp_purchase_pet。图上标橙的这一跳，就是这道白名单实际生效的地方： Agent 不会因为 pet-mcp 以后多暴露几个工具，就顺带多出几样能力。
