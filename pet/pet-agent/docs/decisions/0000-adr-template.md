# NNNN. Short title in the imperative

- Status: proposed | accepted | superseded by NNNN (link the record that replaced this one)
- Date: YYYY-MM-DD

## Context

What forced the decision. The constraint, the conflict, or the thing that was found
during review. Name the alternatives that were genuinely on the table — an ADR whose
context reads "we needed X so we did X" records nothing.

## Decision

One paragraph, present tense, active voice: what we now do.

## Consequences

What this costs and what it makes harder. Be honest here; this section is the reason
someone reading the ADR in a year does not simply reverse the decision on a whim.
