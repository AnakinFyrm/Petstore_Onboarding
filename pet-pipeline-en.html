The one enforced security boundary on this pipeline

pet-mcp itself is free to expose any number of tools, but pet-aes's build_agent() filters whatever toolset it's handed down to exactly the three names PETSTORE_AGENT_SPEC declares — pet_mcp_search_pets, pet_mcp_get_pet, pet_mcp_purchase_pet. The hop highlighted in orange is where that allow-list actually takes effect: the agent never gains a capability just because pet-mcp happens to expose more tools later.
